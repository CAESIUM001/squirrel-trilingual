# 使用与自定义

## 选择对应语言

候选第一行为中文，第二行为英文，第三行为法语。三行左侧显示相同编号；长译文只在自己的候选格内换行。缺失译文不会留下单独的编号。

- 普通数字、空格或点击选择中文。
- `Option + 1–9` 选择英文第一义或当前已经显示的完整英文句子。
- `Shift + Option + 1–9` 选择英文第二义。
- `Ctrl + 1–9` 选择法语词语或句子。
- `Ctrl + Shift + E` 同时开关两种译文；也可通过 Rime 方案选单的“英释／译关”切换。

按键对应当前页的编号。尚无译文时不会提交旧译文，也不会清空当前拼音。若应用或系统已占用相关快捷键，需要先处理快捷键冲突。

## 语言包

通过鼠须管菜单的“英文与法语翻译…”打开设置。随发行包提供的 `Translation Setup.app` 也使用同一设置界面。中英、中法语言包分别下载，首次需完成 Apple 的系统确认。

内置英文词表和 5,000 条法语词表不依赖首次模型下载。英文整句和法语表外内容需要对应模型。设置窗口报告的是当前 Mac 的安装状态；发行包不会附带或分发 Apple 模型。

## 整句翻译

英文：当前高亮候选至少含 6 个汉字、没有词表释义且覆盖完整输入时，停顿约 0.3 秒发起本机翻译。翻译出现后，`Option + 对应编号` 输入完整句子。英文整句只有一个译文，没有第二义。

法语：常用词与缓存命中会随候选直接显示。表外内容停顿约 0.08 秒后开始翻译，优先高亮候选，其余结果逐条显示。词语和整句均可按 `Ctrl + 对应编号` 选择。

单个待译候选最多 300 字符。翻译是基于整个候选的模型结果，不是逐字拼接。部分已确认的中文前缀和未转换拼音后缀在词汇选取时保留；英文整句采用更严格的完整输入要求，以防丢失输入。

## 英文个人词表

编辑 Rime 用户目录中的 `en_gloss/custom.tsv`。通常位于 `~/Library/Rime/en_gloss/custom.tsv`；每行以真实 Tab 分隔中文、第一义、第二义，第二义可省略。

```text
开发	v. develop	v. exploit
学习	v. study	v. learn
```

保存后在鼠须管菜单执行“重新部署”。相同中文键会覆盖随包英文释义；这是个人修正入口，重新安装时会保留。

词性可以省略。支持的常见词性前缀会显示在候选注释中，使用快捷键提交时会去除。词汇显示默认最多 22 字符，显示截断不影响完整译词上屏。

当前方案的自定义 YAML 中，扩展配置可调节英文词义显示：

```yaml
patch:
  en_gloss:
    max_comment_chars: 22
    show_pos: true
    show_second: false
```

已有 `patch:` 时合并到原映射，不要重复添加顶层键；已有安装器管理的 `en_gloss` 区块时，在该区块内修改。`max_comment_chars` 支持 8–80，`show_second` 会同时展示第二义并增加面板宽度。修改前请备份自定义文件。

## 现有双拼用户

公开安装包默认启用雾凇全拼，并保留已有方案。如果希望完全保留现有搜狗双拼及其他输入偏好，可使用[高级手动安装](INSTALLATION.md#高级手动安装已有鼠须管搜狗双拼)，仅安装扩展与前端。

## 当前范围

本项目提供词义显示、英文双义项、英文个人词表、译文上屏、三行候选和本机翻译。尚无青简的生词统计、学习进度或独立主题面板。点击译文区域仍选择中文。机器翻译可能有歧义，请按实际语境核对。
