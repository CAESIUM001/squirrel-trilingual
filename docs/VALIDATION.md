# 验证范围

本说明对应 0.4.0。记录的功能验证环境为 Apple Silicon / macOS 15.6.1，构建使用 Xcode 26.2。自动检查覆盖了代码、真实 Rime 引擎、Apple 本机模型和原生面板；某个聊天框是否接受系统输入法，仍取决于该应用的实际键盘与输入法连接。

## 法语速度

[延迟探针结果](../tests/native/translation-latency/results.json)使用发布的 5,000 条静态词表和实际翻译源代码，在独立辅助应用中测量固定样例：

| 场景 | 首批结果 | 全部结果 |
| --- | ---: | ---: |
| 首次加载词表，9 个常用词 | 约 3.3 ms | 约 3.3 ms |
| 8 个词表命中词，加 1 个新句子 | 约 8.7 ms | 约 129 ms |
| 重复相同内容，全部命中内存 | 约 0.003 ms | 约 0.049 ms |

这些数字不包含宿主应用绘制和控制器等待时间；Apple 模型服务可能已预热，设备、模型状态和句子长度都会影响实测结果。测试的“首次”指当前辅助进程首次查词，不代表整台机器的模型冷启动。

速度改进来自常用词直接查表、缓存同步返回、表外内容等待缩短至约 80 ms，以及按结果完成顺序更新显示。它不意味着 Apple 翻译模型本身被加速，也不保证所有输入都能在上述时间内完成。

## 安装与真实应用

安装器的 45 项检查在可销毁临时目录中运行，覆盖配置合并、保留、备份及故障恢复，没有执行系统安装器的特权 PKG 流程。记录中附有被测原生辅助工具的 SHA-256。

全拼载荷已在临时用户目录中通过安装与真实引擎测试，包括输入 `beijing` 后显示英文释义并用 Option 选词、`nihao` 普通中文提交，以及完整全拼句子的候选生成。该测试跳过系统输入源注册与激活，也不接管当前用户的输入法。

最终 PKG 已完成 327 项解包与内容检查。其辅助工具 SHA-256 与 45 项安装器检查记录一致，具体值及包校验值见结果文件。PKG 保持未签名、未公证状态；解包后的本地临时签名检查不改变这一事实。

可在仓库根目录复现包检查，第二个参数必须是尚不存在的新目录：

```sh
python3 installer/tests/verify_package.py \
  "installer/dist/Squirrel-Trilingual-0.4.0-macOS-arm64.pkg" \
  "installer/build/verified-pkg-0.4.0"
```

源代码检查、临时目录安装、解包签名通过和输入源注册成功是不同层面的结果。完整新用户的特权 PKG 安装及不同应用中的真实键盘使用仍需要单独确认。

输入法可在某个普通文本框工作，并不自动证明其他应用的编辑器也兼容。快捷键还可能先被系统或应用截获。报告问题时，请提供应用和系统版本、输入方案及固定复现步骤，避免上传私人输入或整个 Rime 用户目录。
