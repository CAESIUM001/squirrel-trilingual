# 鼠须管伴词 · Squirrel Trilingual 0.4.0

输入中文时，在每个候选下方同时显示英文与法语，并用快捷键直接输入对应译文。三行序号与正文对齐，默认横向 9 候选，长译文在各自候选格内换行。

## 本版功能

- **法语显示更快**：新增 5,000 条本地中法词表，常用词随候选直接出现；最近译文从内存缓存读取。表外内容短暂停顿后优先翻译当前高亮候选，并逐条显示结果，无需等待整页完成。
- **`Ctrl + 1–9` 选择法语**：对应当前页的词语或整句；译文未完成时保留当前输入。已有中文前缀和未转换拼音后缀继续保留。
- **英文功能保留**：232,213 条离线英文词条，`Option + 1–9` 选择第一义或已显示的完整英文句子，`Shift + Option + 1–9` 选择第二义。
- **本机词句翻译**：使用 Apple Translation 的已下载模型处理英文整句与法语表外内容；无需账号、API key 或云翻译服务。

## 下载与安装

下载下方附件中的 **`Squirrel-Trilingual-0.4.0-macOS-arm64.pkg`**，使用 **`SHA256SUMS`** 核对文件后打开安装。源码可从本仓库或 GitHub 自动提供的源码归档取得。

安装包适用于 **Apple Silicon Mac、macOS 15 或更新版本**，目标机器不需要 Python 或 Xcode。默认使用雾凇全拼，启用横向 9 候选、左右 Shift 切换中英文、三行译文及选词快捷键。当前没有 Intel 安装包。

安装器会先备份已有 Rime 用户目录与用户级鼠须管，再合并配置。已有方案、个人短语、英文译词覆盖和用户词频库会保留；雾凇全拼会成为首选方案，上述候选布局和快捷键默认值会应用。希望完全保持现有搜狗双拼及其他输入偏好的用户，可按仓库的高级手动安装说明仅更新扩展和前端。

**首次使用还需要下载 Apple 中英、中法语言包并完成系统确认。** 安装器会尝试打开设置窗口，也可从鼠须管菜单进入“英文与法语翻译…”。语言包未就绪时，内置英文与法语词表仍可使用，表外实时翻译暂不可用。
