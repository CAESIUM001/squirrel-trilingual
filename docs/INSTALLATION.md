# 安装、更新与恢复

## 系统要求

- Apple Silicon Mac。
- macOS 15 或更新版本，使用完整的英法本机翻译功能。
- 已登录的图形桌面用户，用于安装和启用该用户的输入法。
- 首次下载 Apple 中英、中法语言包时需要网络与系统确认；下载完成后的翻译在本机进行。

普通用户使用 PKG 安装包，不需要安装 Python、Homebrew 或 Xcode。当前没有 Intel 安装包。

## 使用安装包

从[本项目发布页](https://github.com/CAESIUM001/squirrel-trilingual/releases/latest)下载 `Squirrel-Trilingual-0.4.0-macOS-arm64.pkg`，核对发布页中的 SHA-256 校验值，然后双击开始安装。

当前 PKG 未签名，内含应用采用本地临时签名，没有 Developer ID 或 Apple 公证。若 macOS 提示无法验证开发者，请先核对下载来源，再按系统提供的确认流程处理。安装器不会自动移除隔离属性、关闭 Gatekeeper 或修改安全策略。

安装器为当前登录用户放置输入法，尝试注册、重新部署并选中鼠须管。新安装默认使用雾凇全拼，横向 9 候选，左右 Shift 均切换中英文，并启用三行译文及英文、法语选词快捷键。

已有安装会先完整备份 Rime 用户目录与用户级 `Squirrel.app`，再合并所需配置。雾凇全拼会放到方案列表首位，已有其他方案继续保留。个人短语、英文个人译词和用户词频库会保留；本项目的候选数量、方向、Shift 和翻译功能默认值会应用到配置。

备份保存在：

```text
~/Library/Application Support/Squirrel Trilingual/Backups/<本次安装标识>/
```

请保留安装器显示的备份位置。对于复杂配置，安装器会在无法安全处理时报告问题，避免猜测或直接覆盖。

## 第一次启用

1. 在菜单栏的输入法列表选择“鼠须管”。若尚未出现，在系统设置的键盘／输入法设置中添加鼠须管；必要时退出并重新打开使用输入法的应用，或注销后重新登录。
2. 使用中文全拼输入一个词，确认中文候选及词表释义正常出现。
3. 打开鼠须管菜单中的“英文与法语翻译…”。安装器也会尝试打开相同的语言包设置窗口。分别点击中英、中法下载按钮，并完成 Apple 提示。
4. 语言包就绪后，输入一个较长句子，等待对应译文出现，再用 `Option + 编号` 或 `Ctrl + 编号` 选择。

语言包属于当前 Mac 的 Apple Translation 环境，不能因安装包已安装就认为语言包也已就绪。没有模型时，内置英文词表和 5,000 条法语词表仍然可用。

## 更新

使用新版本安装包更新；每次更新先建立独立备份。请勿同时启动多个安装器。鼠须管伴词保留上游输入源标识，替换的是鼠须管前端；直接安装官方鼠须管更新会恢复官方候选面板，因此无法继续显示本项目的三行布局。

本定制前端已关闭上游自动更新检查。请从本仓库发布页获取匹配的前端、Lua 插件及资源，不要只替换其中一个组件。

## 恢复安装前状态

如果安装过程中发生错误，安装器会尝试恢复原文件并核验恢复操作；原始备份会保留。若自动恢复也失败，错误消息会明确说明，并给出可用于恢复的备份位置。

当前 PKG 没有公开的一键恢复命令。需要主动恢复时，可按以下顺序处理自己的备份：

1. 先切换到 ABC，并关闭正使用该输入法的应用。
2. 将当前 `~/Library/Rime` 和 `~/Library/Input Methods/Squirrel.app` 另行保存到新目录。这里可能已有安装后的新词频或个人修改，不能直接丢弃。
3. 查看本次备份中的 `manifest.json`，确认原来是否存在 Rime 目录和用户级鼠须管。将备份中的 `Rime`、`Squirrel.app` 分别放回原位置；使用完整目录恢复，避免把更新后的文件混进旧配置。原先不存在的项目没有对应备份，不要伪造或从其他机器补入。
4. 注销并重新登录，再从菜单栏选择原输入法。核对个人设置后再决定是否清理另存的新状态。

PKG 的完整备份与下方高级 Python 工具的增量备份格式不同，不能混用恢复命令。若恢复前后还需合并新词频或复杂自定义项，请保留两个版本并逐项比较。

## 高级手动安装：已有鼠须管、搜狗双拼

适合已有可用鼠须管和雾凇搜狗双拼、希望保留当前方案与输入偏好的用户。手动方式需要 Python 3，并需要本项目匹配的定制 `Squirrel.app`；可按[构建说明](BUILD.md)生成。

在仓库根目录运行：

```sh
python3 tools/manage.py install --schema double_pinyin_sogou --no-reload
python3 tools/manage_frontend.py install "/path/to/custom/Squirrel.app"
```

第一步安装 Lua 插件及英文词表，并向指定方案的自定义文件合并扩展区块。第二步备份并替换前端、加入三行布局设置、注册实际安装路径并重新部署。不能仅更新前端而保留旧 Lua：法语快捷键需要两个组件共同支持。

手动工具保留已有默认方案、候选数量与左右 Shift 设置。使用其他雾凇方案时，将 `--schema` 换成实际的方案 ID。默认 Rime 路径为 `~/Library/Rime`；默认前端路径为 `~/Library/Input Methods/Squirrel.app`。非默认路径可分别使用 `--rime-dir` 和 `--target` 明确指定。

工具支持常见的两空格缩进、块状 `patch:` YAML。遇到已有同名扩展、重复键或无法安全合并的 YAML 时会停止；按 `schema-patch.yaml` 手工合并前请先备份。

手动安装会在 Rime 用户目录的 `en_gloss-backups/` 中分别记录插件与前端备份。使用安装输出中的路径恢复：

```sh
python3 tools/manage_frontend.py rollback "/path/to/frontend-backup"
python3 tools/manage.py rollback "/path/to/plugin-backup"
```

这些工具会检查安装后文件是否已被修改。多个版本的备份应从最新一层逐步恢复，避免跨过后续改动。它们与 PKG 安装器的完整备份格式不同，不要混用恢复工具。

## 排查

- **有中文和词汇释义，没有整句翻译**：检查对应 Apple 语言包是否已下载，及候选是否符合[整句条件](USAGE.md#整句翻译)。
- **仍是原版单行注释**：确认运行的是本项目定制前端，且三行布局配置已部署。
- **按快捷键切换了桌面或触发应用操作**：检查系统或应用对 `Ctrl + 数字`、`Option + 数字` 的占用。
- **仅某个应用不接受输入法**：先确认其他普通文本框能否使用，再重开该应用。提交问题时附上应用名称、版本和复现步骤。
- **部署报错**：查看 Rime 部署日志和安装器报告，优先定位冲突的配置项；不要清空用户词库来尝试修复。
